#### Descrição do projeto



Aplicativo desenvolvido em Java no Android Studio, utilizando SQLite para o armazenamento local de dados. O projeto implementa as operações CRUD (Create, Read, Update e Delete), permitindo cadastrar, consultar, atualizar e excluir pessoas, além de listar registros, visualizar um resumo dos cadastros e limpar os campos da interface.



#### Tecnologias utilizadas: 



###### Java, XML, Android Studio e SQLite.
